# Project SOLMAR: Unity HDRP

The Unity 6 version of Port Solmar, rendered with the High Definition Render Pipeline (HDRP). The
first part ported from the browser version is the downtown street at golden hour after rain. As
there, nothing is imported: the textures, meshes, sky and lighting are all generated by code
when the scene loads. The project has no model, image or HDRI files.

## Open it

1. Install **Unity Hub** and **Unity 6 (6000.0 LTS)** from <https://unity.com/download>. The
   project was written for 6000.0.23f1; any 6000.0 release should work. If Unity Hub asks which
   version to use, pick the 6000.0 release you installed.
2. In Unity Hub, choose **Add > Add project from disk** and select this `unity` folder.
3. Open the project. The first import sets up HDRP and compiles its shaders, which takes a few
   minutes.
4. Choose **Window > Rendering > HDRP Wizard** and press **Fix All**. This creates the HDRP asset
   and makes HDRP the active pipeline. Accept any dialogs it shows, and let Unity restart if it
   asks to.
5. Choose **Solmar > Create Street Scene**. This:
   - turns on the HDRP features the look needs (see below);
   - creates `Assets/Solmar/Scenes/Street.unity` with the generated city, a camera at the hero
     spot, and markers for the other camera spots;
   - bakes the textures on the GPU (a second or two), then builds the street.

The city is generated in the editor as well as in Play mode, so you can fly around it in the
Scene view straight away.

## Look around

- **Scene view:** hold the right mouse button and use `W A S D`, with `Q`/`E` for down and up.
- **Play mode:** press Play and use the same controls. `Shift` moves faster.
  - `F` switches to walking at eye level. Click to capture the mouse, and use `W A S D` with
    `Shift` to run. `Esc` releases the mouse; `F` again flies.
  - `[` and `]` move the time of day by 15 minutes, and holding `T` fast-forwards. The day
    starts at 18:16 on 26 September, with the sun low in the west-southwest.
  - `F2` saves a screenshot to `unity/Screenshots/`.
- **Screenshots to send:** **Solmar > Capture Spot Screenshots** saves a 1920×1080 PNG of every
  camera spot to `unity/Screenshots/`.
- **Camera spots:** under *Camera spots* there are *Hero*, *Crossing* and *Puddle*. Select one
  and choose **GameObject > Align View to Selected** to view it in the Scene view.
- **Settings:** select *Solmar City* in the Hierarchy. You can change:
  - **Texture Size:** 2048, or 1024 on GPUs with less memory;
  - **Seed:** building colours, puddles and the other variations;
  - **Sun Elevation** and **Sun Azimuth:** the time of day.

  Then choose **Solmar > Regenerate City**.

## What's in it

- **Textures:** seamless PBR sets baked into GPU textures by `ProceduralTextures.compute`, using
  periodic simplex noise, fBm and Worley noise. There are nine sets: wet asphalt, pavement slabs,
  concrete, stucco, painted steel with chips and rust, glass, granite, galvanised and brushed
  metal. Each set has an albedo, a normal map from the height field, and an HDRP mask map
  (metallic, cavity AO, smoothness), with mipmaps and 16× anisotropic filtering.
- **Street:** a crowned road that drains to the gutters, 15 cm granite kerbs with ramps at the
  crossing, and pavements. The road has wheel-path ruts, where the puddles collect.
- **Road decals:** the markings and the puddles are HDRP decals.
  - Markings: a double yellow centre line, lane dashes, edge lines, a continental crosswalk and
    stop lines, all with worn paint.
  - Puddles: standing water in the ruts and gutters. It is darker, flat and mirror-smooth, with
    damp edges.
- **Wet surfaces:** HDRP's clear coat is the water film on the road, kerbs and pavement.
- **Buildings:** Art Deco, MiMo, classic and glass towers.
  - Windows are recessed into the walls and have real rooms behind the glass. Some rooms are
    lit, some have blinds.
  - Shopfronts have lit interiors.
- **Street furniture:** street lamps, traffic signals with lit LED heads, hydrants, litter bins,
  pay stations, signs, drains, manhole covers and a roadworks area.
- **Palms:** planted in granite-edged tree pits with mulch and ground cover.
- **Street details:** a bus shelter with a lit advert and its stop sign, benches, bollards at the
  kerb ramps, newspaper boxes and a bike rack.
- **Parked cars:** sedans, hatchbacks, SUVs, pickups and the odd taxi along both kerbs, with
  lofted bodies, wheel arches, tinted glass, five-spoke wheels and clear-coated paint. They keep
  clear of the crossing, the hydrants and the roadworks, and sit on the road's camber.
- **Daylight:**
  - HDRP's Physically Based Sky with volumetric clouds and volumetric fog.
  - A 120,000 lux sun at 12° elevation, turned golden by the atmosphere.
  - 4096² PCSS shadows and contact shadows.
  - A realtime reflection probe covering the street.
- **Sound:** synthesised live, with no audio files: distant traffic, cars passing across the
  stereo field, gusts in the palms, birds and a faint city hum.
- **Camera:**
  - A physical 35 mm camera with automatic exposure and ACES tone mapping.
  - SSR (also on glass), GTAO, bloom, depth of field, chromatic aberration, vignette, film grain
    and a warm grade.

## Code

`Assets/Solmar/`:

| File | What it does |
| --- | --- |
| `Runtime/SolmarCity.cs` | The component that generates everything, and clears it when disabled |
| `Runtime/Core/` | `Rng` (seeded random), `Shapes` (lathe, sweep, tube, extrude, chamfered box), `MeshBuilder` |
| `Runtime/City/Layout.cs` | Street dimensions: lanes, parking, kerbs, pavements, crossing, lamp spacing |
| `Runtime/City/Street.cs` | Road and pavement surfaces, and `Street.Height(x, z)` for placing things |
| `Runtime/City/Buildings.cs` | Building massing, facades, windows and rooms |
| `Runtime/City/FurnitureParts.cs`, `StreetFurniture.cs` | Street furniture models and where they go |
| `Runtime/City/Palms.cs` | Palms and tree pits |
| `Runtime/City/RoadDecals.cs` | Markings and puddles |
| `Runtime/Rendering/ProceduralTextures.cs`, `Shaders/ProceduralTextures.compute` | GPU texture baking |
| `Runtime/Rendering/CityMaterials.cs` | HDRP/Lit and HDRP/Decal materials |
| `Runtime/Rendering/Atmosphere.cs` | Sun, sky, fog, exposure, post-processing, reflection probe, camera |
| `Runtime/FreeCamera.cs` | Fly camera for Play mode |
| `Editor/SolmarMenu.cs` | The **Solmar** menu |

Coordinates match the browser version: metres, y up, the street along x, and the kerbs at
z = ±9.

## HDRP features it turns on

**Solmar > Create Street Scene** (or **Solmar > Configure HDRP Asset** on its own) turns these on
in the active HDRP asset, because a new HDRP asset leaves some of them off:

- screen space reflections, and screen space reflections on transparents;
- volumetric fog and volumetric clouds;
- decals;
- screen space ambient occlusion;
- directional shadows at up to 4096², with High (PCSS) filtering.

The Console lists anything it changed.

## Status

The code is type-checked against Unity 6.0's published C# source and HDRP 17.0's source, for the
editor and for player builds, and the compute shader is compiled kernel by kernel. CI runs this
on every push; to run it yourself, use `tools/unity-check/check.sh` (it needs the .NET 8 SDK and
glslang). The project has not yet been run inside the Unity Editor, so the first run may still
show problems. If it does:

- **Errors in the Console:** copy the first few (the text and the file:line) and send them.
- **It looks wrong:** send a screenshot of the Game view.

## Troubleshooting

| Problem | What to do |
| --- | --- |
| Everything is pink or magenta | HDRP isn't active: run **Window > Rendering > HDRP Wizard > Fix All** |
| "HDRP isn't the active render pipeline" | The same: run the HDRP Wizard, then **Solmar > Create Street Scene** again |
| "assign the texture compute shader…" warning | Run **Solmar > Create Street Scene**, which fills in the references |
| Package errors about HDRP when the project opens | **Window > Package Manager**: install *High Definition RP* at the version your Unity offers |
| The camera doesn't move in Play mode | **Edit > Project Settings > Player > Active Input Handling**: choose *Both* or *Input Manager (Old)* |
| Slow, or out of GPU memory | Set **Texture Size** to 1024 on *Solmar City*, then **Solmar > Regenerate City**. At 2048 the textures take about 0.8 GB |
| Very dark or very bright for a moment | Automatic exposure adapts over about a second |

**Known limitation:** the materials are created at runtime, so a standalone build (File > Build)
doesn't yet include their shader variants. Play mode in the editor is the way to run it for now.
Builds will get a shader variant collection when the game has a build pipeline.
