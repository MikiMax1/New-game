# Project SOLMAR

An original open-world crime game in the spirit of GTA VI, set in the fictional Miami-inspired city of Port Solmar. Claude builds it in this repository with Three.js and TypeScript, and it runs in the browser. The map comes first, realism second, gameplay third.

See [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) for the milestones and how the work is done.
